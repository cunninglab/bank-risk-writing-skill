# report-outline 规则对照

示例主题为虚构，只用来说明写法。

## 1. 章节数由材料决定

材料：一份消费者权益保护通知原文，没有数据。
❌ 七章提纲，其中“国际经验比较”“量化影响测算”两章在材料中找不到任何依据。
✅ 四章提纲；“量化影响”列入建议补充材料：“需要投诉数据，才能写影响测算。”

## 2. 章节标题写观点或任务

❌ “三、风险概况”
✅ “三、投诉集中在理财销售环节，适当性管理是主要薄弱点”（观点）
✅ “三、梳理投诉的分布特征，识别薄弱环节”（任务）
查数型章节可以用中性描述：“附表：分渠道投诉量（2023–2025）”。

## 3. 材料不足时交付初步框架

❌ 只有一段新闻摘要，却给出了完整的五章提纲，并写了具体结论。
✅ “以下为基于现有材料形成的初步框架。现有材料只能支撑第一、二章；第三至五章需要补充通知原文和机构披露数据。”

## 4. 结构选与用途最匹配的一种

用途：向管理层汇报。
❌ 套用政策研究的六段式结构，从“背景”写起。
✅ 选汇报逻辑“总体结论 → 关键支撑 → 主要问题 → 建议动作”，并说明：“受众为管理层，结论先行。”
