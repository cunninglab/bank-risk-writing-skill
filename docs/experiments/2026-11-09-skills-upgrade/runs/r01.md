# 银行业保险业普惠金融高质量发展实施方案政策简报

**核心结论：**《实施方案》将2023年国务院普惠金融总体部署，进一步落实到银行业保险业的服务体系、信贷供给、数据应用和组织保障等方面。对银行风险管理而言，重点是适应信用贷款、续贷和中长期贷款等业务安排，强化第一还款来源分析、数据真实性核验和贷款存续期监测。相关安排多属既有政策的细化或落实，不能一概认定为首次提出或风险标准放宽。

## 一、文件概况

国家金融监督管理总局办公厅、中国人民银行办公厅于2025年6月19日印发《银行业保险业普惠金融高质量发展实施方案》，文号为**金办发〔2025〕58号**，2025年6月26日公开发布。方案明确落实国务院2023年普惠金融实施意见及2025年金融“五篇大文章”指导意见，适用于银行业保险业相关工作。文件未另行明确生效日期。[《实施方案》原文](https://app.www.gov.cn/govdata/gov/202506/26/531673/article.html)

以下对比主要以[2023年国务院实施意见](https://chinajob.mohrss.gov.cn/h5/c/2023-10-13/388717.shtml)和2024年普惠信贷、续贷及尽职免责专项通知为依据，**不代表对所有既有政策的穷尽性比较**。

## 二、核心要点：文件明示内容

- **发展目标。**未来五年基本建成高质量综合普惠金融体系；在保持信贷投放力度的同时，优化信贷结构、防控信贷风险，健全成本可负担、商业可持续的长效机制。
- **机构定位。**大中型商业银行应结合自身特点制定普惠金融战略、明确业务边界；地方中小银行应坚守支农支小定位，立足当地特色经营。
- **小微与涉农信贷。**落实续贷政策，加大首贷、续贷、信用贷投放；优化审批模型，强化对企业经营情况等第一还款来源的分析；支持特定用途的中长期贷款。在风险可控前提下，支持对小额农户贷款开展非现场贷前调查，并加强信息真实性核查。
- **管理与数据。**完善监管评价及信贷政策导向效果评估，深化信用信息共享；支持金融机构在依法合规、充分授权前提下运用数字技术提升服务和风控能力。
- **综合服务。**方案同时部署普惠保险产品、服务和监管工作，并支持探索将农业保险保单信息作为涉农贷款信用评级参考。

以上见[《实施方案》原文](https://app.www.gov.cn/govdata/gov/202506/26/531673/article.html)。

## 三、与此前政策相比的主要变化和延续

| 比较事项 | 此前政策与本方案的对应关系 | 对变化的审慎判断 |
|---|---|---|
| 政策层级和实施重点 | 2023年国务院意见部署机构体系、风险分担、信息基础设施和监测评估等综合事项；本方案面向银行业保险业，对机构定位、信贷和保险服务作出行业安排。 | 主要是**将总体部署行业化、具体化**；综合普惠和安全发展并非本方案首次提出。 |
| 信贷评价和投放 | 2024年普惠信贷通知提出年度“保量、稳价、优结构”，并提出普惠型小微企业贷款增速目标；本方案提出科学设定监管目标、优化指标、突出实效评价，同时保持有效增量供给。 | 本方案更侧重五年发展框架和评价机制。**不能据此推定此前年度指标已取消**，具体考核仍须核对适用的年度政策。 |
| 授信依据和数据 | 2024年通知已提出首贷、续贷、信用贷及数据应用等方向；本方案明确提出强化第一还款来源分析、降低对抵押物的过度依赖，并提出使用资金流信用信息共享平台。 | 体现对经营信息和数据运用的具体化；不意味着抵押担保或审慎授信要求被取消。 |
| 续贷和责任认定 | 2024年续贷通知已扩大符合条件企业的续贷安排，并明确特定条件下不因续贷单独下调风险分类；2024年尽职免责通知已规定适用范围、认定和内部制度要求。本方案提出积极落实续贷新政策。 | 续贷及尽职免责是**既有专项政策的落实**，不宜表述为本方案新创设的普遍免责或自动续贷。 |
| 涉农业务工具 | 2023年意见已涉及农村金融、农业保险和信用环境建设；本方案进一步提出探索利用农业保险保单信息作信用评级参考，并在风险可控前提下支持小额农户贷款非现场贷前调查。 | 本方案对两个具体应用场景作出部署；其表述分别为“探索”和有条件的“支持”，不能当作统一强制流程或风险转移保证。 |

## 四、对银行风险管理的可能影响

以下为基于公开文件的分析，**不是方案直接规定的新增内部制度要求**。

1. **信用风险识别可能更依赖经营与现金流信息。**信用贷投放、降低对抵押物的过度依赖，以及设备更新、研发等中长期贷款支持，可能提高对借款人经营真实性、现金流稳定性和期限匹配判断的依赖。不同客户和用途的风险特征仍需结合本行实际数据评估。

2. **续贷存续期管理的重要性可能上升。**续贷可缓解符合条件客户的阶段性资金压力，但仍需区分暂时性困难与持续偿付能力恶化。既有规则中“不因续贷单独下调分类”有适用条件，不能理解为续贷后无需持续判断风险。[2024年续贷政策说明](https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=1180104&generaltype=0&itemId=915)

3. **数据、模型和合作方风险可能更受关注。**资金流、共享信用信息和数字化工具有助于丰富授信判断，但数据授权、真实性、时效性及模型适用性可能影响判断质量；第三方合作与客户综合融资成本也需一并关注。

4. **涉农贷款的真实性核验和风险缓释评价可能更复杂。**非现场调查可能提高服务效率，也可能增加身份、经营和贷款用途核验难度；农业保险保单信息可作为评级参考，但保障范围、期限及理赔条件是否覆盖具体风险，需要具体分析。

5. **业务可持续性需要结合风险成本观察。**方案同时提出降低综合成本、保持投放及防控风险。银行可能需要结合客户、产品和期限，观察定价、运营成本与实际信用损失之间的关系；目前公开方案不足以判断对某家银行盈利或不良率的具体影响。

## 五、后续关注和待核实事项

- **监管指标：**核对适用于本行的现行年度普惠信贷目标、统计口径和评价规则，关注方案所述监管评价优化及制度修订的后续安排。
- **续贷与免责：**结合现行专项规则核对客户资格、风险分类、尽职认定和留痕要求；方案本身不替代相关细则。
- **数据与非现场调查：**核实共享数据的授权、质量和使用条件，以及当地对小额农户贷款非现场调查的具体适用口径。
- **组合表现：**结合本行实际，观察信用贷、续贷、中长期贷款及涉农贷款的逾期、迁徙、损失和期限结构，避免将政策方向直接等同于风险结果。
- **资料边界：**本简报依据公开文本比较，未覆盖全部地方配套政策或本行内部制度；正式使用前建议核对相关文件现行有效状态。指定 skill 所列验收测试文件在当前工作区缺失，已依据可读取的写作规则及核查清单自检。
