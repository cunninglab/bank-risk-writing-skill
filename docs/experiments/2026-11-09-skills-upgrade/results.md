## 实验中发现、留待后续处理的问题

本轮不修改文本、不追加试跑（方案 5.5），以下问题只记录：

1. **C1.4 的来源标注缺口。** `rules/core.md` 第 3 节只要求标出“用户提供”，没有要求检索来源标“自行检索”。policy-brief 的新版和去除 M1 共四次运行，三次因此不通过 C1.4。修改 core 会使所有 skill 的现有证据失效，需要新一轮验证。
2. **C4.3 与 C4.4 普遍偏低。** 新旧版本的 C4.3（删句测试）大多是 0 分。报告提纲和简报的章节标题多是话题标签或写作任务，C4.4 得 0。新版在这两条上没有改善。
3. **ppt-outline 新版出现过程叙述**（C4.2 得 0）：“已检索到……但打开时正文未加载，故未将搜索摘要中的数据用作基准”。
