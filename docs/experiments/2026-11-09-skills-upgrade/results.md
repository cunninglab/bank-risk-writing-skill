## 实验中发现、留待后续处理的问题

1. **C4.3 与 C4.4 普遍偏低。** 报告提纲和简报的章节标题多是话题标签或写作任务，C4.4 得 0 或 1；删句测试中总有 1–3 句可删。新版在这两条上没有改善。
2. **“待核实线索”的写法容易被当成过程叙述。** `rules/core.md` 第 3 节要求未加载的页面列入“待核实线索”；r13、r16 写成“检索到……但页面未加载……”，评审判 C4.2 为 0。可以考虑在内核中给出不带过程叙述的线索写法。
3. **支撑点复述核心信息。** 去掉“3–5”之后，r16 没有凑数（每页 2 点），但支撑点复述了本页核心信息。规则 3 只约束了数量和长度，没有要求支撑点提供核心信息以外的依据。
4. **policy-brief 最终版仍未满足 C1 闸门。** `rules/core.md` 第 3 节补上“自行检索”标注后，C1.4 在 r15 中通过；但 r15 引用的报告页面没有发布日期，模型按内核写了“发布日期待核实”，按 C1.2 字面口径仍不通过。要彻底解决，要么由检索流程找到报告的发布页面（例如人民银行网站上的发布栏目页）取得日期，要么修改标准、承认“如实标注待核实”。后者是标准变更，需要用户决定。
